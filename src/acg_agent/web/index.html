用一句话描述你想看的动画，每部结果都附上判断依据。

欢迎使用如月寮

第一次使用需要准备数据：从 Bangumi、bangumi-data、VNDB 的官方来源下载约 650 MB 的数据包，并在你的电脑上导入，大约需要几分钟。数据只保存在你自己的电脑上。

数据准备好了，可以直接搜索。现在只用规则理解一句话（免费、最快）；想用 AI 理解复杂的说法、用代理人，在右上角“设置”里选服务商、填你自己的 Key（推荐智谱 GLM：免费、国内直连）。
